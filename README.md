 📌 Project Overview

The Advanced Scientific Calculator is a desktop application designed to perform a wide range of mathematical and computational operations through an easy-to-use graphical interface.

The project was developed as part of an internship project to demonstrate practical knowledge of:

- Python programming
- GUI development using Tkinter
- Event handling
- Mathematical operations
- File-based project organization
- Keyboard interaction
- Data processing
- Graph plotting
- Software testing and documentation

---

## ✨ Features

### 🧮 Basic Calculator

The calculator supports:

- Addition
- Subtraction
- Multiplication
- Division
- Percentage
- Power operations
- Decimal calculations
- Brackets
- Clear
- Backspace

---

### 🔬 Scientific Calculator

Scientific functions include:

- Sine (`sin`)
- Cosine (`cos`)
- Tangent (`tan`)
- Inverse sine (`asin`)
- Inverse cosine (`acos`)
- Inverse tangent (`atan`)
- Common logarithm (`log`)
- Natural logarithm (`ln`)
- Square root (`√`)
- Square (`x²`)
- Cube (`x³`)
- Factorial (`x!`)
- Reciprocal (`1/x`)
- Pi (`π`)
- Euler's number (`e`)

---

### 📐 DEG / RAD Mode

The calculator supports two angle modes:

- DEG — Degree mode
- RAD — Radian mode

This allows trigonometric calculations to be performed according to the selected angle unit.

---

### 💾 Memory Functions

The calculator provides memory operations:

- **MC** — Memory Clear
- **MR** — Memory Recall
- **M+** — Memory Add
- **M−** — Memory Subtract
- **Ans** — Insert Previous Answer

---

### 📊 Statistics Mode

Statistics Mode allows users to enter multiple numbers separated by commas and calculate:

- Count
- Sum
- Mean
- Median
- Mode
- Minimum
- Maximum
- Range
- Population Variance
- Population Standard Deviation
